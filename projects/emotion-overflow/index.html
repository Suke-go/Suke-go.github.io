Emotion Overflow

Representing emotion with fluid

Period
2024–2025
Threads
T2Interfaces for Reconnecting with Memory
Links
  • Web Demo
  • YouTube

Emotion Overflow turns a short text about how someone feels into an interactive fluid simulation. It starts from a common figure of speech in which the body is a container and emotion is what overflows from it. In the demo, the fluid fills a round display and moves when the user touches it by hand.

In the UIST 2024 version, a GPT model reads the text and estimates emotion attributes, focusing on valence and arousal. These values set properties of the fluid: its color, how much it varies over time, and how strongly it responds to interaction. The paper demonstrates two experiences: direct visualization of an emotion, and an emotion-guessing game.

The web demo at ksk432.com/EmotionOverflow is a browser version built on a WebGL fluid solver. It classifies English text into six basic emotions with an open text-emotion model, converts the result to valence, arousal and dominance, and maps these to color, viscosity, time step and touch force. The work was also presented at INTERACTION 2025.

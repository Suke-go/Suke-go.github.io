GhostDisplay

A moving fog screen that passes through the user

Period
2024
Team
Kosuke Shimizu, Shogo Fukushima, Kenji Suzuki
Links
  • YouTube

Fog screens and other immaterial displays let people walk through an image, but they are usually fixed in place. GhostDisplay mounts a fog screen on a linear actuator, so the screen itself moves toward the user and passes through their body.

Moving the screen raises two problems. Fog left behind along the path also catches the projection and makes the image look multi-layered, so a micro blower clears the residual fog. The projection distance also keeps changing, so a focus-free laser-beam-scanning projector with a MEMS mirror keeps the image sharp at every position.

The prototype combines a fog machine with a duct hose, a linear-guide actuator, a distance sensor and a Raspberry Pi 5. The work is documented in a video; there is no published paper.
